# Research Notes 静态网站

这是一个不依赖框架的纯静态网站，适合保存每周学习与汇报。

## 本地打开
直接双击 `index.html` 即可。

## 当前页面
- 首页目录
- 9.7~9.14 周报
- 4 篇论文详细页

## 后续新增一周
1. 复制 `weeks/2026-09-07_09-14.html`
2. 改文件名与页面内容
3. 在 `index.html` 增加一个新的 week card
4. 如有新论文，在 `papers/` 中复制一个详细页并修改内容

## 部署
可直接把整个文件夹上传到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态网站服务器。
